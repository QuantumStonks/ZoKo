01 / INPUT
Question types and confidence

choice selects one key from a criteria object. noul returns a probability between 0 and 1. score uses an ordered criteria array with 2–10 levels, beginning at zero.

Confidence is provider-reported. For noul, Zoko derives confidence as max(p, 1 − p). It is not measured accuracy.

A quote is free. Schema-valid results are billed, including results below your confidence threshold.
